# Bundled Noto Sans SC

Unmodified Simplified Chinese subset OTFs from the official Noto CJK project:
https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC

Downloaded 2026-10-04 from `main`:

- `NotoSansSC-Regular.otf`: `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`
- `NotoSansSC-Bold.otf`: `c6cb5a93abaa9edc8ee7463b7ebb7f42d618d40e6ed2f7a5371c97b0b64767c0`

SHA-256 hashes identify the exact bundled files. Original upstream license is
preserved in `OFL.txt` (SIL Open Font License 1.1, from `Sans/LICENSE`).
The two OTFs total approximately 16 MiB and are embedded into the native binary.

UI family chain: `Go, Noto Sans SC`; monospace family chain:
`Go Mono, Noto Sans SC`. System font discovery is disabled. A character already
covered by Go remains in Go; missing characters fall back to Noto Sans SC.
Disclosure triangles are drawn geometry rather than font glyphs.
