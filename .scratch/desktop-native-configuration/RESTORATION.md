- 总览采用名称／协议、端点／模型、Slave ID、状态表格；删除旧对象卡片与重复总览标签。

- 导航与主区滚动条覆盖显示，不再始终占用内容宽度。YAML 隐藏导航、占满剩余高度并在编辑器内部滚动。

## 保留差异

- Go 配置的上游没有名称字段，因此显示由协议生成的入口名称；不会为了截图加入不被配置支持的名称字段。
- 原型为只读 YAML 投影，正式页面保留实际 YAML 编辑、核心校验和冲突流程。
- 字体栅格化及控件的键盘交互来自 Gio，不宣称逐像素相同；本轮未验证 Windows／Linux 的实际图形窗口，也未重新测量性能。
- 原型底部用于切换方案和状态的黑色工具条不属于产品界面。
