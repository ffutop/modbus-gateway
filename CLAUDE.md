## Agent skills

### Issue tracker

Issues and PRDs live in local Markdown under `.scratch/<feature>/`; external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five triage roles, recorded with `Status:` in local tickets. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single repository context: `CONTEXT.md` and `docs/adr/` when present; otherwise use the domain vocabulary in `AGENTS.md` and the current implementation. See `docs/agents/domain.md`.
