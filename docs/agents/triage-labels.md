# Triage labels

用户于 2026-10-05 选择默认词汇。本地文件使用 `Status: <role>`。

| Role | Value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 已明确，可交给实现代理 |
| ready-for-human | ready-for-human | 待人工实现 |
| wontfix | wontfix | 不处理 |

ready-for-agent 表示需求可实施，不表示需求已经实现或测试通过。
