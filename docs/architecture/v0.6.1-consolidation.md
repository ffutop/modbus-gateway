## 验证结果

使用 `go version go1.24.3 darwin/amd64`。

- 根模块 `go test ./...`、`go vet ./...`、`go build -o modbus-gateway .`：通过。
- 桌面模块 `go test ./...`、`go vet ./...`：通过。
- 桌面 `go test -race ./internal/sidecar ./internal/configfile ./internal/runlog`：通过。
- `test/` 模块 `go test -v ./...`：通过（约 27.6 秒）；socat 虚拟串口、管理接口、sidecar 退出及共享模拟持久化均实际执行。
- Windows amd64 桌面交叉构建：通过。
- 设计令牌重新生成：通过；`tokens.json` 与 `tokens_gen.go` 无差异。
- macOS amd64/arm64 打包：通过，Info.plist 和本地 ad-hoc 签名检查通过。
- Windows amd64/arm64 打包：通过。
- 全部新提交的信息规范检查及全部打包 shell 脚本语法检查：通过。
- Linux 打包未运行：本机为 macOS，没有 Linux 原生 CGO/图形开发环境；对应脚本和 CI 与对照提交一致。

迁移期间既有 RTU `TestScanLoop` 出现一次 “Simulated response not written” 时序失败，复跑通过；该包已有竞争问题，未在规整任务中修改其实现或扩大 race 检查。交叉构建、打包和离屏测试不能代替 Windows/Linux 实机交互、文件选择器、剪贴板与输入法验收。
