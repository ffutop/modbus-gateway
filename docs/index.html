Modbus Gateway Multi-Master · Multi-Slave Router

A high-performance Modbus gateway written in Go. Supports arbitrary TCP / RTU / RTU-over-TCP protocol bridging, Slave ID-based routing across multiple downstreams, and a built-in local virtual slave.

Download Binary Documentation

Architecture

Slave ID routing dispatches each request to the correct downstream. Serialized queuing prevents bus conflicts.

Full Protocol Support

TCP, RTU, and RTU-over-TCP on both upstream and downstream, mixed freely.

Slave ID Routing

Route requests to different downstreams by Slave ID. Supports ranges and lists.

Local Slave

Built-in virtual slave with memory, file, or mmap persistence.

Multi-Master Concurrency

Multiple masters with per-downstream serialization queues.

RS485 Control

Full RTS timing control for industrial serial converters.

pprof Profiling

Optional pprof endpoint for CPU / heap / goroutine diagnostics.

Quick Start

1. Build

bash
git clone https://github.com/ffutop/modbus-gateway.git cd modbus-gateway go build -o modbus-gateway

2. Run

# Start with a config file
./modbus-gateway -config config.yaml

Configuration

All behavior is driven by config.yaml. See the Configuration Reference below.

# pprof profiling server (optional)
pprof:
  enabled: false
  address: "localhost:6060"

gateways:
  - name: "gateway-1"
    upstreams:
      - type: "tcp"
        tcp:
          address: "0.0.0.0:502"
    downstreams:
      - type: "rtu"
        slave_ids: "1-10"
        serial:
          device: "/dev/ttyUSB0"
          baud_rate: 19200
          data_bits: 8
          parity: "N"
          stop_bits: 1
          timeout: "500ms"
      - type: "local"
        slave_ids: "100"
        local:
          persistence:
            type: "mmap"
            path: "/data/"

log:
  level: "info"
  file: ""

Configuration Reference

Complete field reference for config.yaml.

pprof

Enables Go's built-in pprof HTTP server for runtime diagnostics.

Field Type Default Description
pprof.enabledboolfalseSet true to start the pprof HTTP server.
pprof.addressstringlocalhost:6060Listening address for the pprof server.

gateways[]

Array of independent gateway instances. Each runs its own upstream listeners, routing logic, and downstream connections.

Field Type Description
namestringHuman-readable label for logs.
upstreamsarrayList of master-side listeners.
downstreamsarrayList of slave-side targets with routing rules.

upstreams[]

Each entry defines one listener. Multiple upstreams share the same downstream pool.

Field Value / Type Description
typetcp · rtu · rtu-over-tcpProtocol the master uses to connect.
tcp.addressstringListen address for tcp / rtu-over-tcp.
serial.*see SerialSerial port settings for rtu type.

downstreams[]

Each entry defines one slave target. slave_ids controls routing — leave empty to match all.

Field Value / Type Description
typetcp · rtu · rtu-over-tcp · localSlave connection type. local = built-in virtual slave.
slave_idsstringRouting rule. Formats: "1" · "1,2,3" · "1-10". Empty = match all.
tcp.addressstringRemote address for tcp / rtu-over-tcp.
serial.*see SerialSerial port settings for rtu type.
local.persistence.typememory · file · mmapStorage backend for the local virtual slave.
local.persistence.pathstringDirectory path for file / mmap backends.

serial fields (used in rtu upstreams & downstreams)

Field Default Description
device—Serial device path.
baud_rate—Baud rate.
data_bits8Data bits.
parityN"N" · "E" · "O"
stop_bits1Stop bits.
timeout500msRead timeout per request.
rqst_pause100msMinimum pause between consecutive requests.
rs485falseEnable RS485 RTS signal control.
delay_rts_before_send0RTS assertion delay before sending.
delay_rts_after_send0RTS de-assertion delay after sending.
rts_high_during_sendfalseKeep RTS high during transmission.
rts_high_after_sendfalseKeep RTS high after transmission.

log

Field Default Description
log.levelinfo"debug" · "info" · "warn" · "error"
log.file""Log file path. Empty = stdout.
